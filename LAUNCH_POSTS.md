## LinkedIn (professional)
Introducing JeeG: task automation without an AI model.

Many everyday tasks (calculating GST or EMI, renaming files, setting timers, tracking expenses, opening the right site) do not need a language model. Sending them to a cloud service costs money, energy and privacy; running a model locally costs memory and time.

JeeG takes a different approach. You type a task in plain words, it matches your words against a library of 421 small scripts, and runs the right one on your own machine.

- Private by design: no account, no telemetry, nothing leaves your computer unless a task is explicitly about the internet. Your data is stored in a folder only you can read.
- Light: pure Python standard library, about 65 ms per command, nothing in the background.
- Predictable: the same words give the same result, and `explain` shows why a task was chosen.
- Safe: confirmations for risky actions, undo for file moves, hardened link, archive and import handling.
- Extensible: write a plugin in one file; Windows, macOS and Linux supported and tested in CI.

Indian everyday use is built in: GST, EMI, SIP, RD, invoices, lakh/crore, PIN code lookup, IRCTC and PNR.
