How it works

No model, no cloud

Each script starts with a few header lines. JeeG scores your words against them and runs the best match. Nothing runs in the background.

1. You type

Plain words in any order. A typo or two is fine.

2. It matches

Names, keywords and patterns are scored. If two tasks fit, a short menu appears.

3. It checks

Anything that can lose data asks first. Preview mode shows what would happen.

4. It runs

The script gets your leftover words, does one job and prints the answer.

Safety

Careful with your files

What it protects

  • Risky tasks ask first. Deletes move files to a holding folder.
  • undo restores your last move or rename and never overwrites.
  • Only safe link types open. Archives cannot write outside their folder.
  • Your data folder is private on Mac and Linux. Password tasks are never saved to history.

What it does not do

  • It never sends your files or personal data anywhere.
  • No voice mode and no pop-up window yet.
  • Online tasks were tested on recorded replies, not live services.
  • Tested on Linux. Windows and macOS parts are not yet run on real machines.
Install

Two commands

Needs Python 3.9 or newer. Works on Windows, macOS and Linux.

Install
pip install jeeg
First-run setup, then start it
jeeg setup

No pip? Download the folder from GitHub, open a terminal inside it and run python install.py.

Or run one task directly
jeeg emi loan 25 lakh 8.5% 20 years
Check everything works
jeeg selftest
