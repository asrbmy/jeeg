# Programs, Network and Shop

## Install and set up programs
Each asks first; add `preview` to see only the command.

    install vlc and git
    uninstall vlc
    update all apps
    install dev bundle        (also: office, media, student, privacy)
    configure git name Ravi email ravi@example.com
    is git installed
    set env variable API_URL to https://example.com
    add ~/tools to path

JeeG knows about 45 popular programs and picks the package name for your package manager (winget or choco on Windows, brew on Mac, apt, dnf, pacman or flatpak on Linux). Other names are passed as typed. On Linux it may ask for your password in the terminal.
