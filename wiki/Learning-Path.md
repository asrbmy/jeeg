# Learning Path

A week of short sessions (about 15 minutes each). Each day ends with something you can check.

## Day 1: Install and say your first words
Read [Install and First Run](Install-and-First-Run). Run `jeeg doctor`, then `jeeg`, then try `open youtube`, `25 * 4`, `weather in pune`, `exit`.
*You are done when:* `doctor` shows no problems and you have run three different tasks.

## Day 2: Learn how it chooses
Read [How JeeG Understands You](How-JeeG-Understands-You). Type `explain open youtube` and `explain play shape of you`. Type something silly and see "No matching task". Make an ambiguous request (`open youtube`) and note how to be more specific.
*You are done when:* you can say why one task won and what a `<- tied (menu)` line means.

## Day 3: Find tasks
Type `list`, `list money`, `list files`. Open the [Task Catalog](Task-Catalog). Try one task from five different categories. Type `tips` for one you have not tried.
*You are done when:* you know three categories you will use.

## Day 4: Keep your own records
Read [Reminders and Personal Records](Reminders-and-Personal-Records). Add a to-do, a note, an expense, a reminder in 2 minutes, and a habit. Then `search my data <word>`.
*You are done when:* a reminder fired and `weekly summary` shows your data.

## Day 5: Make it yours
Read [Routines, Aliases, Variables and Automation](Routines-Aliases-Variables-and-Automation). Create an alias, a variable (`set var rate = 18`), edit a routine, run `batch` on a small file.
*You are done when:* one daily job runs with a single short word.

## Day 6: Safety and your data
Read [Safety and Privacy](Safety-and-Privacy). Run `privacy`, `export data`, `backup status`, and a delete task with `preview`.
*You are done when:* you know where `~/.jeeg` is and have a backup zip.

## Day 7: Pick a direction
- Developer? [Use JeeG From Code](Use-JeeG-From-Code) and [Plugins and Writing Your Own Tasks](Plugins-and-Writing-Your-Own-Tasks).
- Use AI apps? [AI Mode and MCP](AI-Mode-and-MCP) and [Linked Apps](Linked-Apps).
- Want automation of websites? [Real Web Browser](Real-Web-Browser).
- On the go? [Phone, Web Page and Connectors](Phone-Web-Page-and-Connectors).

## Reference habits worth keeping
`explain <words>` when a task surprises you, `preview` before anything destructive, `doctor` when something seems wrong, `misses` to see what JeeG did not understand, `stats` to see what you use.
